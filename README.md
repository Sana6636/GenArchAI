# GenArchAI 🏗️

**AI-Powered Architectural Design and Renovation Assistant**

GenArchAI is an AI-powered architectural assistant designed to help users generate, analyze, and renovate building designs. It combines generative AI, conversational interfaces, architectural visualization, and cost estimation to support the design process.

## ✨ Features

* 🏠 AI-assisted architectural design generation
* 🎨 Design visualization and presentation mode
* 🔄 Building renovation assistance
* 💬 AI architectural chat assistant
* 💰 Construction cost estimation and budget optimization
* 📊 Design analysis and scoring
* 📁 Project workspace and project management
* 🖼️ Upload and analyze architectural designs

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Sana6636/GenArchAI.git
cd GenArchAI
```

### 2. Install frontend dependencies

```bash
cd client
npm install
```

### 3. Install backend dependencies

```bash
cd ../server
npm install
```

### 4. Configure environment variables

Create the required `.env` files locally using the provided `.env.example` as a reference.

**Never commit API keys, passwords, or Firebase service-account credentials to GitHub.**

### 5. Run the application

Start the backend and frontend using the scripts/configuration provided in their respective directories.
